## ✨ Highlights

- **Preloader** — animated 0→100% counter with curtain reveal (CSS kill-switch fallback, never traps the page)
- **Floating dock nav** — auto-hides on scroll, active-section tracking, mobile sheet menu
- **Light / dark theme** — toggle with `localStorage` memory
- **Hero** — oversized typography, live IST clock, typing roles, magnetic CTA buttons
- **Bento cards** — tilting live-code terminal, recruiter quick-view (copy-email, stats counters)
- **Skills marquee + animated proficiency bars** with category filters
- **Filterable projects** (Vision / GenAI / Apps) with case-study modals
- **Experience timeline, education, "Hire me as" role cards, contact panel** with Formspree form
- **Mickey-head cursor** — inversion-blend so it's visible on every background; desktop-only, touch-safe
- **SEO + a11y** — meta tags, JSON-LD person schema, reduced-motion support, fully responsive

## 🛠 Stack

Single `index.html` — no build step, no frameworks. Vanilla HTML + CSS + JS, Google Fonts (Sora / Inter / JetBrains Mono), Font Awesome icons.

## 🚀 Run locally

Just open `index.html` in a browser, or serve it:

```bash
npx serve .
# or
python -m http.server 8000
```

## 🌐 Deploy (GitHub Pages)

1. Push to this repo (already done).
2. Repo **Settings → Pages → Deploy from branch → `main` / root**.
3. Site goes live at `https://pavanraj08.github.io/Portfolio/`.
